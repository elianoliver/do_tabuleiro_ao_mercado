# Do Tabuleiro ao Mercado — React + Vite

Reescrita simplificada da landing page original em Angular.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

## Configuração

Atualize `src/config.ts` com o link real da Hotmart, e-mail, redes sociais e Analytics.

## Arquitetura

- `src/App.tsx`: composição das seções e interações da página.
- `src/content.ts`: textos e dados editáveis.
- `src/config.ts`: checkout, contato, produto e Analytics.
- `src/styles.css`: tema visual e responsividade.

O projeto usa apenas React, Vite e Lucide. Angular, Tailwind e Three.js não são necessários.
